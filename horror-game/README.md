# 靜默病棟 SILENT WARD

第一人稱網頁恐怖遊戲。手機和電腦的瀏覽器都能玩，不用安裝。

> 1999 年 8 月，聖羅莎紀念醫院在一連串失蹤事件後封院。二十年後，你帶著攝影機獨自走進七樓，想拍下傳說中「哼歌的女人」。直播訊號在踏進大廳的那一刻中斷，身後的大門鎖上了。

**目標**：在醫院裡找到三個保險絲，插回發電機房的配電箱。三個都插上之後，大門的電子鎖會打開，但她也會發狂。跑出大門就贏了。

也支援遊戲手把（左搖桿移動、右搖桿看、A 互動、X 手電筒、Y 相機、B 蹲、LT 奔跑、RB 丟瓶子、按住 LB 屏息）。

建議戴耳機。所有聲音都有 3D 定位，隔著牆會變悶，你可以用耳朵判斷她在哪裡：她一邊走一邊哼著布拉姆斯的〈搖籃曲〉，哼歌聲跟著她移動；腳步一重一輕、走路與奔跑的節奏不同；她停下來聽的時候會傳來很輕的呼吸。大約 30 公尺內聽得到，越近越大聲，隔一道牆就變小、變悶。她在 15 公尺內出聲時音樂與環境音會稍微讓開，而且這時候不會有「假的」腳步聲、耳語或音樂盒來混淆你。設定裡的「她的聲音提示」可以選關／標準／加強（加強：她的聲音大約 +5 dB、40 公尺內都聽得到）。

## 遊戲特色

- **每一局都是新的醫院**：走廊、病房、手術室、太平間、護理站、發電機房的配置與道具位置都是程序生成，並經過自動驗證，保證每個道具都拿得到。
- **六種樓層**：主選單的「地圖」可以選「隨機」或指定樓層，每一層的格局、房間、牆面地板、燈光顏色、霧色、家具與貼花都不一樣：
  - **7F 七樓病房區**：一切開始的地方。長走廊、成排的病床與隔簾、手術室、護理站。
  - **B1 地下太平間**：沒有窗戶的地下室。整面到頂的冷綠磁磚、冷藍綠色的燈、地上的排水孔；一整面一整面的冷藏櫃，有些抽屜被拉出來，上面躺著蓋白布的屍體；不鏽鋼解剖台、天花板吊軌上掛著一排屍袋、寬敞的停屍走廊。
  - **4F 兒童病房**：剝落的粉彩條紋壁紙、粉彩方格地板、暖黃色的燈。嬰兒床、小病床、新生兒室、遊戲室的小桌椅、會自己搖的搖搖馬，地上散落著泰迪熊、積木、皮球和洋娃娃，牆上貼滿孩子的蠟筆畫——畫裡那個長頭髮的白衣女人一直在找她的孩子。
  - **9F 精神科隔離區**：鈕扣軟墊包覆的隔離室、束縛床與攤在床上的約束衣、門邊的觀察窗、鐵籠般的護理站、電療室的電擊椅、交誼廳。小房間又多又密。
  - **5F 手術部**：「手術綠」的油漆牆與整面磁磚的手術室、冷白色的燈。雙頭無影燈下蓋著綠色手術布的手術台、麻醉機與生理監視器；加護病房一床一床用隔簾隔開，床頭是監視器；刷手間的一長排刷手槽、無菌器械室的滅菌鍋；走廊上掛著半透明的塑膠條門簾，地上一條紅色的無菌區警戒線。
  - **3F 燒毀的舊院區**：那一夜之後燒毀的舊大樓。越往上越黑、火舌形狀的燻黑牆面與碳化龜裂、捲起燒焦的地磚與灰燼；煙灰色的霧、餘燼般的橘色緊急燈；天花板塌下來的瓦礫堆把幾段走廊整個堵死（瓦礫縫裡還有悶燒的餘燼），坍塌病房裡是斷樑和燒剩的床架，天花板破洞垂下礦纖板與電線，破窗被木板釘死。
  - 格局也會變：每一局先抽走廊拓樸——棋盤格（再抽 L 形缺角或 U 形中庭）、拆掉一部分走廊的不規則街區、環狀走廊包著中央街區、環狀走廊圍著天井（四面看得到天井的窗）、H 形、偏向一側的魚骨形主走廊加長短不一的側翼。不規則的街區會被切成大小不一的房間，貼不到走廊的「內室」只能從隔壁房間的門穿過去；再加上雙倍寬的大走廊、死路支線與堵住走廊的路障，同一種樓層每一局的平面圖都很不一樣。
  - 同一組「種子＋難度＋樓層」一定生成同一張地圖（「隨機」也是先由種子決定樓層），「再試一次」會回到同一層樓。
- **會思考的她**：平常一邊哼搖籃曲一邊遊蕩；聽到你奔跑、開關門會過來查看；看到你會停止哼歌、發出尖叫並追上來；失去目標後會在附近搜索。手電筒開著、站在燈下時她更容易看到你，蹲下則不容易被發現。
- **察覺與提示**：她看到你不會馬上追——會先停下腳步、轉過來盯著你，「察覺值」從 0 慢慢累積到 1，滿了才尖叫追上來（3 公尺內幾乎馬上）。越近、開著手電筒、站在燈下、站著（沒蹲）累積得越快；她已經在查看聲音或搜索時也更快。這段時間內轉過牆角、關掉手電筒、蹲下躲開她的視線，察覺值就會慢慢退掉，她會繼續做原本的事。
  - 畫面上方中央有一隻眼睛：她注意到你時睜開，隨察覺值由骨白轉琥珀再轉成血紅，過半之後眼白爬滿血絲、四周透出紅光；全紅加上毛筆血字「她發現你了！」、畫面邊緣紅一下，就是她開始追了——追你的時候整個提示會一直發抖。提示的字用跟紙條同一套毛筆字型。其他時候會有一行小字：「她聽到聲音了」（耳朵，她去查看你弄出來或你附近的聲音）、「她在附近找你」（她在你附近搜索、或在你躲的櫃子外面側耳傾聽）、「她跟丟了」（追逐結束）；多人時她在追隊友會顯示「她在追 ＸＸ」。同一句 8 秒內不會重複。
  - 準心外圍的弧形箭頭指向她（她在背後也看得到）：察覺中、或她在 20 公尺內追逐 / 查看 / 搜索時出現，顏色跟眼睛一樣。
  - **她身邊的紅光**：她在同一層、12 公尺以內時，身後浮著一圈暗紅色的光暈，附近的牆和地板也被染紅；越近越亮，平常像呼吸一樣慢慢明暗，追人時跟著急促的心跳用力閃。她消失、被送走、在別層時完全熄掉。這是她自己發出的光（場景裡的東西），所以「察覺提示」關掉時也還在。
  - **畫面邊緣的血紅色**：她越近、越注意你，畫面四邊越往內滲進血紅色，她在哪一側那一側比較濃（她在背後就是下緣；3 公尺內四周一起紅），跟著心跳一縮一放；畫面中央永遠是乾淨的，最濃也只到七成左右。「察覺提示」關掉時不顯示。
  - 第一次被注意到時會提示「她注意到你了——躲開她的視線！」；開場的教學提示也會教你關手電筒、蹲下、躲鐵櫃，以及上方眼睛的意思。
  - 設定裡的「察覺提示」可以關掉（預設開啟）：關掉之後沒有眼睛、箭頭、小字與畫面邊緣的紅色，但她一樣要先盯著你一下才會追。
  - 多人時由房主為每個人算察覺值，隨女鬼狀態送出她目前目標的察覺值（取到 0.05）與目標編號；每個人只看得到針對自己的那一份，箭頭用同步過來的女鬼位置。
- **躲藏與屏息**：躲進鐵櫃，她就找不到你——除非她親眼看到你躲進去。她在櫃子外停下來側耳傾聽時，要屏住呼吸；憋不住大口喘氣，她就會聽到。
- **門禁卡與上鎖的房間**：每一層有一到兩間上鎖的房間（藥局、院長室、保全室、器械庫……依樓層不同），門上有一條顏色的色條，門外的讀卡機亮著紅燈。對著門按互動會告訴你要哪一種顏色的卡（「上鎖了（需要紅色門禁卡）」）。同色的門禁卡一定放在不用開任何鎖就拿得到的地方（同一層或別層），撿到之後右上角會出現一張小卡片，對著門刷卡，讀卡機轉綠、門就永遠開著，卡片用掉。鎖著的房間裡有好東西：有時候是三個保險絲之一（每層最多一個），不然就是三捲底片、鎮定劑和電池。她也打不開鎖著的門：還鎖著的房間對她來說就是牆，裡面是安全的死路；刷卡開了之後就變成普通的門，她會自己推開走進去。
- **遺物與儀式（另一個結局）**：她失去的孩子留下了三件遺物——嬰兒鞋、出生手環、一張舊照片——散落在醫院各處（多層樓時分散在不同樓層，有時候一件鎖在上鎖的房間裡）。撿起來會看到一小段文字，右上角顯示「遺物 放回數/3（+身上帶著的）」。把它們放回劇情房間（707 病房、0713 冷藏室、嬰兒室、0713 隔離室、第 7 手術室、313 病房……撿起遺物時會告訴你搖籃在哪一層、哪一間）裡點著蠟燭的搖籃。每放回一件，她就更生氣：燈閃、尖叫、更快更敏銳，醒著的話會往搖籃找過來。三件都放回去時，音樂盒自己轉了起來，她出現在搖籃旁低頭哼完最後一次搖籃曲，然後就不見了——這一局她不會再出現。儀式不會打開大門：還是要插上三個保險絲通電才出得去，但接下來再也沒有人追你，走出大門會看到「安息」結局。儀式是選擇性的，不做也能照原本的方式逃出去。
- **丟玻璃瓶**：把撿到的瓶子丟到遠處，摔破的聲音會把她引過去；追逐中只要她暫時看不到你，也能用來甩開她。
- **相機閃光**：直播用的相機閃光燈可以讓她僵住幾秒，但底片有限。
- **理智值**：待在黑暗中、看到她、被追都會讓理智下降，畫面會扭曲、出現耳鳴和低語，甚至看到不存在的東西。理智歸零時她會知道你在哪裡。燈光和鎮定劑能讓你冷靜。
- **電力與節奏**：每插上一個保險絲，就有更多燈亮起，她也變得更敏銳、更快。最後一個插上時警報響起，全館通電，大門外的路燈亮起，展開最後的逃亡。
- **手機震動**：被發現、被抓、看見她時，支援的手機會震動。
- **驚嚇導演**：門會自己甩上、身後傳來腳步聲、遠處電話響起、音樂盒自己轉、輪椅在黑暗中滑動、轉身後牆上多了血字、走廊盡頭站著一個白色身影……依你的理智與進度動態安排。
- **七份紀錄**：散落的筆記拼出她的故事，也藏著求生提示。全部讀完會看到另一個結局。
- **多人連線（最多 4 人）**：主選單按「多人連線」，一個人「建立房間」，把 5 碼房間代碼告訴朋友，朋友輸入代碼「加入」，房主按「開始遊戲」。大家在同一棟醫院裡，看得到彼此的人物和手電筒、聽得到彼此的腳步；門、道具、保險絲、牆上的血字都會同步，同一個道具只有一個人拿得到。她會追離她最近的人。被抓走的人改成觀戰（互動鍵換人看），所有人都被抓或逃出後一起看結算，然後可以回大廳再玩一局。
  - 連線用 WebRTC 點對點（[PeerJS](https://peerjs.com/) 的公用伺服器只負責牽線），遊戲資料不經過伺服器。公司或學校等嚴格的防火牆可能連不上。
  - 房主負責女鬼和事件，房主的分頁請保持在前景；房主離開時這一局會結束。遊戲開始後不能中途加入。
  - 載入比較慢的人：房主等 90 秒還沒載入完就先開始；晚到的人載入完時，房主會送一份現在的世界狀態（開了的鎖與門、被拿走的道具、插上的保險絲、放回的遺物、鐵捲門、她是不是已經安息），每一項都會核對過才套用。
  - 多人時電池、鎮定劑、底片、玻璃瓶依人數多放（每多一個人：電池多 40%、鎮定劑多 35%、底片與瓶子多 25%）——每個人的手電筒各自耗電，道具卻只有一份。
  - **多層樓**：多人連線時醫院的樓層數依難度決定——簡單 1 層、普通 2 層、惡夢 3 層（大廳資訊列會顯示）。有大門的那一層是你選的地圖，其他樓層由種子挑不同的主題，上下順序照樓層編號（地下太平間一定在最下面）。樓層之間用樓梯間連接：對著樓梯按互動，畫面一暗、一陣腳步聲，就到了另一層對應的樓梯口。發電機房在離大門最遠的那一層，三個保險絲與七張紙條分散在各層，大廳的平面圖會寫發電機房在哪一層。
  - 只畫你所在的那一層；其他樓層的玩家看不到、聽不到。她也有自己所在的樓層：追你的時候會跟著走樓梯上下樓，你在別層待太久她也會找過來；不在同一層時看不到她、也聽不到她的哼歌和腳步聲。地圖（M）顯示目前這一層、各層列表與走過的樓梯。
  - 單人固定 1 層；網址加 `?floors=2` 或 `?floors=3` 可以測試多層樓。
  - **倒地與扶起**：多人時，最後一條命被她抓到不會馬上被帶走，而是倒在地上（簡單 40 秒、普通 30 秒、惡夢 25 秒；畫面暗紅、心跳、只能很慢地爬、不能互動），她也會先退開一下。其他人看到的你是趴在地上、雙手往前伸、手腳交替慢慢往前爬（不動時就趴著喘氣）。隊友站到你旁邊（同一層、1.6 公尺內）按住 E（手機按住「互動」）3 秒，準心旁的進度環跑滿，你就會站起來，但理智很低。每個人每一局只能被扶一次；時間內沒人扶、或還在裡面的人全部都倒了，就會被帶走（改成觀戰）。
  - **雙人鐵捲門**：開局時 2 人以上，整棟醫院會有 1～2 道沉重的鐵捲門擋住走廊，把手在同一側幾公尺外的牆上。要一直按住 E 轉把手才拉得起來，一放手整片就摔下來（很大聲，她也聽得到；站在下面的人會被推到旁邊，不會卡在裡面）——所以要一個人顧把手、其他人通過。她也過不去關著的鐵捲門（要拉到八成以上才過得去，摔下來時站在下面的她一樣會被推到旁邊），只能繞路；鐵捲門只會擋住捷徑（或後面只放額外好東西的死路），不會擋住必經的路；裡面只剩一個人時，鍊條會卡住、停在打開的位置。
- **三種難度**：簡單（可以被抓一次）、普通、惡夢（她更快更敏銳、電池稀少、沒有地圖）。最佳通關時間會記錄在瀏覽器裡。

### 難度與平衡

玩家走路 2.55 m/s、奔跑 4.6 m/s（體力 6.5 秒，簡單 8.5 秒）、蹲走 1.25 m/s、倒地爬 0.32 m/s。她追人的速度 = 3.45 m/s ×難度倍率 ×（0.85 + 0.15 ×憤怒），發狂（大門打開後）是 4.15 m/s 起算。憤怒 = 1 + 0.15 ×保險絲 + 0.12 ×放回的遺物，大門打開後至少 1.5；感知（看、聽）照憤怒放大，但**速度最多只算到 1.6 倍憤怒**：插滿保險絲又放回兩件遺物（憤怒 1.69）時，普通難度的她發狂是 4.52 m/s（以前 4.58，只比全力奔跑慢 0.02），惡夢是 5.20 m/s（以前 5.27）——惡夢的最後逃亡本來就要靠閃光、瓶子和躲藏。

| | 簡單 | 普通 | 惡夢 |
|---|---|---|---|
| 她追人的速度（開局 → 憤怒上限） | **2.76 → 3.01 m/s**（原 2.93 → 3.20） | 3.45 → 3.76 m/s | 3.97 → 4.32 m/s |
| 發狂時（上限） | **3.62 m/s**（原 3.85） | 4.52 m/s | 5.20 m/s |
| 視覺距離（蹲下 ×0.62、開手電筒 ×1.45、站在燈下 ×1.2） | **8.4 m**（原 9.6） | **10.6 m**（原 12） | 15 m |
| 被看到 → 開始追（站著、不開燈、不在燈下、7 公尺） | **約 1.4 秒** | **約 0.9 秒** | **約 0.5 秒** |
| （以前：三種難度都一樣、沒有任何提示） | 約 0.8 秒 | 約 0.8 秒 | 約 0.8 秒 |
| 追逐中看不到你幾秒就跟丟 | **2.4 秒**（原 3.2） | **2.8 秒**（原 3.2） | 3.2 秒 |
| 跟丟後在附近搜索 | **11 秒**（原 16） | **14 秒**（原 16） | 16 秒 |
| 電池一顆撐多久 | 329 秒 | 230 秒 | 170 秒 |
| 散落的電池 / 底片 / 鎮定劑 / 瓶子（單層） | 8 / 4 / 4 / 6 | 6 / **2**（原 3）/ 3 / 5 | 4 / **1**（原 2）/ 2 / 4 |
| 開局底片 | 3 | 2 | 1 |
| 她第一次出現（每多一層 +25%） | **90 秒**（原 75） | 50 秒 | 30 秒 |
| 多人倒地等人扶 | **40 秒** | 30 秒 | **25 秒** |

察覺值的累積速度：基準（上表，7 公尺）乘上距離倍率 (7 ÷ 距離)^1.6（0.35～12 倍；3 公尺內至少 4.5 倍），開手電筒 ×1.35、站在燈下 ×1.25、蹲下 ×0.6、她在查看 / 搜索時 ×1.5、理智歸零 ×2，再乘上憤怒。看不到時每秒退 0.4；跟丟之後從 0.55 開始退。發狂（大門打開後）時她照舊直接追過來；理智歸零時她隔著牆也知道你在哪（25 公尺內），察覺值累積兩倍快。

上鎖的房間裡另外有一捲三張的底片、鎮定劑和電池（有保險絲的那間只放鎮定劑），所以普通和惡夢散落的底片各少放一捲，開鎖才是拿底片的主要方式。多層樓時散落的道具總量是單層的 1 + 0.5 ×（層數 − 1）倍，再依人數加成。

## 畫面與聲音

- 女鬼是寫實的 3D 人物：以 Microsoft Rocketbox 的護理師模型（MIT 授權）為基礎，重畫成死白發青的皮膚、凹陷的眼窩、混濁的眼睛與血淚，加上濕黏的長黑髮。她有骨架動畫與臉部表情：平常歪著頭、嘴微張，盯上你時會轉頭看你、把頭髮撥開，抓到你時嘴會張到超出人類的極限。模型載入失敗時會自動改用程序生成的版本。

- three.js PBR 材質：牆面以 Poly Haven 的照片掃描貼圖（剝落油漆、髒磁磚、舊塑膠地磚、生鏽鐵板、木頭，CC0）為底，執行時再用 Canvas 疊上程序生成的水漬、黴菌、髒污與磁縫，每局都不一樣；照片載入失敗時整套退回純程序貼圖。
- 手電筒是有即時陰影與投射圖案的聚光燈，會跟著手部晃動略微延遲；電量低或她靠近時會閃爍。
- 整層樓的環境遮蔽、牆角陰影、濕地板反光、光束中的灰塵、閃電照亮的窗戶、閃爍的日光燈（燈光池只讓最近的幾盞燈真的打光，效能友善）。
- 後製：泛光、底片顆粒、暗角、色差、理智扭曲、類比錄影雜訊、受傷紅光、她靠近時畫面邊緣滲進來的血紅色（同一道後製裡多算幾行，不多畫一次全螢幕；省電模式不算流動的雜訊紋理）與醫院色調。
- 紙條：每張紙條、遺物說明都是一張沾滿血的醫院表單——泛黃的紙、表頭與橫線、水漬和霉斑、上緣往下流的血、角落的噴濺、右下角淡淡的血手印與指紋、拖過去的血痕，全部用 Canvas 即時畫（`src/paper.js`，沒有用任何圖片；同一張紙條每次打開都長得一樣）。字是毛筆字，人名、病歷號、「不要回頭」這些關鍵字和每張紙條的最後一段像用血寫的：乾掉的暗紅色、筆畫邊緣有點毛、底下還有往下滴的痕跡。字的大小跟著設定裡的「字幕大小」。
- 毛筆字型：Yuji Boku 為主，它沒有的繁體字（她、你、跑、躲……）用 Ma Shan Zheng，兩個都沒有的（說、產、絕、辦、丟、啟、妳、檔、綁）用 LXGW WenKai TC Bold，三套都是 SIL OFL 1.1。只留下紙條、遺物、樓層 / 房間名稱、牆上的字與察覺提示用到的約 500 個字，三個 woff2 子集加起來約 215 KB，用同一個字型名稱 SWBrush、各自的 unicodeRange 載入，瀏覽器逐字挑檔案；子集以外的字（例如玩家名字）會退回明體，不會變成方塊。牆上的血字也改用這套毛筆字畫。
- 聲音：腳步、開關門、鐵櫃、尖叫、心跳、雨聲、雷聲、玻璃碎裂、相機快門、電話鈴等使用實錄音效（CC0 / CC BY 3.0），她的哼歌與低語、喘息、追逐鼓點、滴水、收音機雜訊則用 Web Audio 即時合成；全部經過卷積殘響、HRTF 3D 定位與牆壁遮蔽。音檔載入失敗時每個聲音都會退回合成版本。
- 配樂：主題是布拉姆斯的〈搖籃曲〉（Wiegenlied, Op. 49 No. 4，1868 年，公有領域），用真實的鋼琴、大提琴、低音提琴、小提琴與鐘琴錄音（VSCO 2 社群版，CC0）即時編排，會跟著情境變化——選單是音樂盒（鐘琴）放著這首搖籃曲、鋼琴輕輕彈分解和弦，發條會晃、偶爾走音或少一個齒，第二遍越走越慢，停下來上發條再重來；醫院裡是一段一段出現、中間留白的稀疏鋼琴與低音弦樂，偶爾從很遠的地方傳來一兩小節音樂盒；她靠近時顫弓慢慢浮上來，被追時她停止哼歌、換成追逐配樂與低音鋼琴重擊；躲進櫃子音樂幾乎消失；逃出去時是鋼琴版的搖籃曲後半段，被抓到時音樂盒越走越慢、停在半句。她哼的也是同一首（即時合成的女聲哼唱），所以聽到搖籃曲就知道是她。設定裡可以分別調整主音量、音效與音樂。
- 病床與推床上躺著寫實的屍體（同樣來自 Rocketbox 人物，MIT）：仰躺、手垂到床外、側身蜷縮、趴著、屍僵舉爪、上半身滑落床外、靠著床頭垂著頭等七種姿勢，皮膚死白、有屍斑、割腕、勒痕、解剖縫線，衣服浸滿血。有時候你轉頭再看，床上的屍體已經換了姿勢。
- 牆上有照片掃描的天花板滲水痕跡與抹開的血跡；恢復電力後，日光燈管會發出跟著閃爍斷續的電流嗡嗡聲。
- 手機會自動選擇較低畫質，並依實際幀率動態調整解析度。
- 手機操作與「按鍵配置」：設定裡可以換成左手模式（搖桿在右半邊、按鈕在左下角）、按鈕大小（小／中／大，最小也有 48px）、視角加速（手指甩得越快轉得越多；慢慢拖動時稍微放慢，方便瞄準），都會記住。按鈕排成以大按鈕為中心的兩圈弧線，避開瀏海與圓角（safe-area），字幕和提示會讓到按鈕旁邊，直立玩時改排到按鈕上方。搖桿中間有死區，推到底往前自動奔跑並輕震一下。
- iOS Safari：擋掉連點放大、雙指縮放、長按選字與選單、整頁橡皮筋回彈（選單與設定面板仍可捲動），第一次碰螢幕就解鎖聲音；iPad 用 webkit 前綴進全螢幕，按「繼續」時會再進一次全螢幕。iPhone Safari 不支援網頁全螢幕，要「加入主畫面」才有。
- 設定裡的「畫面與舒適度」：視野（60～100 度，手機另外加 4 度）、頭部晃動開關（關掉時走路與奔跑鏡頭都不晃、不拉寬視野）、畫面亮度（伽瑪，只提亮暗部；「亮度」是整體曝光）、字幕與提示的大小（80%～160%）。全部會記在瀏覽器裡，遊戲中改了馬上生效。
- 多層樓的醫院在載入時就把每一層的著色器編譯好、各畫一次（只顯示那一層），第一次走樓梯不會卡住。
- 畫面柔和度：低 / 中畫質在最後一道後製裡做 FXAA 抗鋸齒（設定裡的「抗鋸齒」，預設開啟；高畫質用 4 倍多重取樣），底片顆粒與色差調得比較細、比較淡，手電筒照近處的牆不會整團過曝，地上的積水不再反射成一塊塊白斑。動態解析度最多只降到 70%，畫面不會糊成一片。
- 模型細節層次：屍體與女鬼在載入時用 meshoptimizer 產生簡化版本（只換索引、共用頂點與平滑法線），遠處自動換成較少三角形的版本，最遠的屍體不投影。
- 省電與降溫：設定裡可以把更新率上限設成 30（省電）、60（預設）或不限；高更新率螢幕不會再白白多畫一倍的畫面。電腦預設「中」畫質，女鬼不在畫面裡時不繪製，後製濾鏡也合併成較少的全螢幕繪製。電腦或手機發燙時，選「低」畫質加「30 省電」最涼。
- 省電模式（設定裡的「省電模式」：自動 / 開 / 關）：最多 30 FPS、最多 1 倍像素再縮小 15%、關掉泛光。「自動」在瀏覽器支援電池狀態（Chrome、Edge）而且沒插電時開啟，插上電源就關掉，遊戲中切換會提示一下。暫停選單打開、分頁切到背景時（單人）完全不繪製。
- 遠處不畫：濃霧裡深度超過「霧只剩 0.1%」的靜態網格、道具、屍體直接不畫，也不進陰影（用 layers 關掉，不影響其他程式切換 visible；不受霧影響的門外背景照常畫；霧比較亮又看得到門外的樓層不剔除，完全封閉的樓層把背景換成霧的顏色）。試過把牆、地板、天花板改成一個房間一組：每個像素算光照的次數只少了 0～17%（本來就只有 1.1～1.5 次），繪製次數卻多了 25～30%，所以維持 18 公尺一塊；也試過先依距離再依材質排序，重疊繪製反而變多，維持 three.js 預設排序。
- 手電筒陰影：關燈時不畫陰影圖；手電筒沒動時隔一格才重畫一次。關燈、燈光池沒分配到燈時都只把亮度設成 0，不切換 visible——場景裡的燈數一變，所有材質都要重新編譯著色器（以前第一次關手電筒會重新編譯近 20 個著色器、卡一下）。她身邊的紅色點光源也一樣：載入時就放進場景、不投影，平常亮度 0；光暈貼片在載入時跟她一起預先編譯。
- 每格更新不再 new 暫存的向量與顏色；看不到的電視雜訊不重畫，手電筒關掉時光束灰塵整批不畫，門外的雨照常做視錐剔除。

## 開發

需要 Node.js 18 以上。

```bash
cd horror-game
npm install
npm run dev      # 監看檔案並在 http://localhost:8080 預覽
npm run build    # 產生 dist/index.html 與 dist/assets/（一起放到任何靜態主機）
npm test         # 關卡生成模糊測試 + 毛筆字型涵蓋測試 + 無頭瀏覽器端對端測試
```

`npm test` 的端對端測試需要 Chromium；預設路徑是 `/opt/pw-browsers/chromium`，可以用 `CHROME=/path/to/chrome npm test` 指定。

`dist/index.html` 是單一檔案（約 1.3 MB），所有程式和樣式都內嵌在裡面；建置時會把 `assets/` 一起複製到 `dist/assets/`，部署時兩者要放在一起。介面字型從 Google Fonts 載入（離線時會自動改用系統字型）；紙條與察覺提示的毛筆字型在 `assets/fonts/`。

改了紙條、遺物說明或察覺提示的文字之後，要重新產生毛筆字型的子集（不然新的字會退回明體）：

```bash
pip install fonttools brotli
# 原始字型從 Google Fonts 下載：Yuji Boku、Ma Shan Zheng、LXGW WenKai TC（Bold）
python3 tools/fonts/subset.py YujiBoku-Regular.ttf MaShanZheng-Regular.ttf LXGWWenKaiTC-Bold.ttf
node tests/font.test.mjs   # 有字沒涵蓋到就會失敗，並列出是哪些字
```

字集由 `tools/fonts/charset.mjs` 從 `src/level.js` 的紙條、遺物、牆上的字、房間名稱與 `src/themes.js` 的樓層名稱收集，程式裡直接寫的提示字串列在同一個檔案的 `BRUSH_STRINGS`。

### 部署到 GitHub Pages

儲存庫裡附了 `.github/workflows/horror-game-pages.yml`。在 GitHub 的 **Settings → Pages** 把 Source 設為 **GitHub Actions** 之後，每次推送到 `main` 都會自動建置並發佈。
